# Sistema de Gestión para Minimarket Robles - Migración Frontend a Angular

## Descripción

Este proyecto fue desarrollado como parte del curso de JavaScript Avanzado con el objetivo de aplicar los conocimientos adquiridos en el framework Angular.

El proyecto consiste en la migración del frontend de un sistema de gestión web para el Minimarket Robles, originalmente desarrollado en Java utilizando Servlets, Apache Tomcat y MySQL. La aplicación permite gestionar procesos internos del minimarket, incluyendo el control de inventario, registro de productos, administración de stock y generación de reportes de ventas.

Como parte de la migración, se desarrolló una nueva interfaz de usuario utilizando Angular, manteniendo el backend existente y la base de datos original. Esto permitió modernizar la experiencia de usuario sin modificar la lógica de negocio ya implementada.

## Objetivos del Proyecto

* Aplicar Angular en un proyecto real.
* Implementar una arquitectura basada en componentes.
* Reutilizar un backend existente desarrollado en Java.
* Mejorar la experiencia de usuario mediante una interfaz moderna y dinámica.
* Integrar el frontend Angular con servicios y datos provenientes del sistema original.

## Funcionalidades

* Gestión de productos.
* Control y actualización de inventario.
* Administración de stock.
* Registro y consulta de ventas.
* Generación de reportes.
* Navegación entre módulos mediante componentes Angular.

Frontend Angular → Backend Java (Servlets) → Base de Datos MySQL
